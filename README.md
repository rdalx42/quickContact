# Setup Instructions 

# Backend
- Install requierments.txt 
- make a venv and start it
- cd backend and do a python main.py or python3 main.py
- you can customize the port

# Frontend
- init node with svelte env 
- npm run dev
- you can customize the port and the backend port location  

# Core
- Make sure you add the key to SECRETS.json and the email address
